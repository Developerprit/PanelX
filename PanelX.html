服务器运维控制台 · Server Ops Console

把一台服务器的心跳，
装进一个浏览器标签页。

PanelX 是一个 Python 文件：启动即服务，浏览器登录即得实时资源监控、进程管理与系统信息。没有框架，没有依赖，只有标准库。

One Python file. Boot it, open a tab, watch your server breathe — CPU, memory, disk, network, processes, all live.

功能 / What it does

01

实时资源监控

CPU、内存、磁盘与网络使用率，前端每 2 秒自动刷新。

Live CPU / memory / disk / network, polled every 2s.
02

进程管理

列出运行中的进程，支持按 PID 一键终止。

List processes; kill by PID from the UI.
03

系统信息概览

操作系统、主机名、运行时长、Python 与架构一目了然。

OS, hostname, uptime, Python & arch at a glance.
04

登录认证

会话令牌 + 密码加盐哈希，未登录接口一律拦截。

Session token + salted hash; APIs gated.

为什么零依赖？ 运维场景往往不允许随意装包。PanelX 只用 Python 标准库 + 系统调用， 拷贝这一个文件就能在任何装了 Python 3 的服务器上跑起来。 Why zero-dep? Ops boxes often forbid arbitrary installs — one file, any Python 3, done.
